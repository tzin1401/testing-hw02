A-FR02 — Đăng nhập và khóa tài khoản Web

B-FR07 — Giỏ hàng Web

Run bổ sung tạo giỏ bằng đường Home/biến thể riêng, quan sát thêm: cùng sản phẩm không gộp dòng; thiếu nút +/-; xóa không hỏi xác nhận; nhãn “Tổng tạm tính”; phép tính dòng/tổng khớp ở checkpoint. C-FR14 — Quản lý danh mục Admin

23 TC thiết kế: 15 Pass, 4 Fail, 1 Blocked, 3 Observation. Fail gồm tên rỗng được nhận ở UI/biên 0 và API cho phép JWT role user POST/DELETE. GET authorization, whitespace và ID không tồn tại vẫn probes do oracle chưa đủ rõ. Guest checkpoint chỉ cho thấy form Admin Login. Lượt UI bổ sung dùng fixture role user đã xác minh trong DB clone: login API trả 200, Admin UI hiện “Bạn không phải là admin!” và không có admin token. Đây là bằng chứng UI riêng; API write tests vẫn là evidence khác. Xem execution và bug report.

D-MREG — Đăng ký Mobile

Run Pixel 9 emulator phát hiện form chỉ có ba trường, thiếu xác nhận mật khẩu. Trong 20 TC thiết kế, 1 Fail (thiếu field), 15 Partial (thao tác biến thể trên ba field), 2 Blocked (ca xác nhận), 2 Not run (BVA robustness riêng không có evidence hợp lệ). Các biến thể đã chấp nhận họ tên/email rỗng, email không có @, và email trùng; weak password probes bị từ chối. D-BV-002 độ dài 8 gặp network failure nên không kết luận. Các biến thể ba field không được tính Pass/Fail cho test case đầy đủ bốn trường. API-only duplicate test cũng tạo bản ghi thứ hai trên DB cô lập; không dùng API thay UI. Hai lượt automation mới cho D-BV-006/007 không tới được response đáng tin cậy và được loại khỏi kết quả. Xem execution, bug report.
